# Unreleased changes

Changes in current source, not yet included in a packaged release. Historical release notes remain in [the changelog](../apps/desktop/CHANGELOG.md).

- Code Mode: combine supported reads locally, enabled by default. Turn it off in Settings → Chats & autonomy; direct tools remain available.
- Chat activity: readable tool labels distinguish discovery and combined reads. MCP tools no longer appear as terminal commands, including in saved chats.
- Terminal recording: new profiles record Claude Code sessions with Spark’s mod by default. Existing on/off choices are preserved; Codex recording is unchanged.
