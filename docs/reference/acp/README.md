# ACP v1 schema

`schema.json` is the Agent Client Protocol v1 JSON Schema (draft 2020-12), added on September 25, 2026. It is kept byte for byte as downloaded, so Prettier skips it.

- Source: https://agentclientprotocol.com/protocol/v1
- SHA-256 prefix: `3c17bd6385d90cf6`
- What Spark Outpost supports is tracked in `docs/architecture/ACP_COVERAGE.md`.

To update it, replace the file with the newer schema, update the hash above, and re-run the coverage check.
