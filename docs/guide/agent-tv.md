You'll watch the agents on a request and tell one of them something. About 1 minute.

## Watch in Agent TV

1. Select **Agent TV** in the chat header. It appears once the chat's first reply starts.
2. Pick **Stage** to see the agents as blobs, or **List** for one row per agent with its model, time and cost.
3. Select an agent to see its status, then **Go to** to jump to its work in the chat.
4. Press **Esc** to close it.

Agent TV works for any chat. A plain answer shows the agent that answered, plus Jev when it's connected. Builders and the Coordinator appear when they join. It keeps following its chat while you open another one.

## Message a crew member

1. Select **Message** on the agent's row in **Agent TV**, in the **Crew** tab of the **Work** panel, or on its row in the chat.
2. Type your message and select **Send to** _name_, such as **Send to Bolt**.

The agent reads it at its next step. The chat shows it as **You → Bolt**. Nothing waits for an approval: the agent's mode and Spark's safety rules still apply.

When a Builder has finished, the button reads **Continue** _name_. The same Builder picks its work back up in a new turn. If a turn is still running, your message waits in the [queue](queue-messages.md).

> **Tip:** The Critic and the Coordinator see what you told a Builder when they review.
