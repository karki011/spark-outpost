Stop Spark starting work by itself while you step away. About 1 minute.

1. Select **More** at the bottom of the left bar, then **Pause Spark**. On a phone, open **More** too.
2. **Spark is paused** shows at the top; select **Resume** there or **More** → **Resume Spark**; a dot on **More** shows while Spark is paused.

Spark stays paused after a restart.

| Held until you resume                                                                       | Still runs                                           |
| ------------------------------------------------------------------------------------------- | ---------------------------------------------------- |
| Queued messages, when the turn before them ends                                             | A message you send, and **Send now** on a queued one |
| [Messages between chats](chat-messages.md), wrap-ups and **Held** [sub-chats](sub-chats.md) | A message you type in a sub-chat                     |
| [PR follow-up](pr-follow-up.md) rounds; feedback is still read                              | Running turns, their cards and their publish step    |
| The morning brief and [Map](map.md) builds                                                  | Terminal sessions                                    |
| [Scheduled workflows](workflow-schedules.md)                                                |                                                      |

Work started from inside Slack is skipped while paused; start it again after.
