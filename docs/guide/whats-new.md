Earlier releases: **Settings → Updates → Release notes**.

## October 2026

| What changed                      | What to do                                                               |
| --------------------------------- | ------------------------------------------------------------------------ |
| Adjustable Island height          | Slide higher or lower in **Settings → Notifications**.                   |
| Code Mode on by default           | Combine reads; [turn off in Settings](settings.md#code-mode).            |
| Accurate activity status          | Commands pass; tools finish.                                             |
| Agent-led delegation              | Leads [choose workers and slices](how-spark-works.md#how-work-is-split). |
| Chat opening                      | Drafts stay; failures offer **Try again**.                               |
| Outpost messages                  | Messages go to the displayed lead; **Post note** is explicit.            |
| Team in the sidebar               | See worker blobs in the sidebar and Agent TV.                            |
| Agent TV messaging                | Message members or redirect workers in short windows.                    |
| Calmer text and composer          | Tools have readable labels; details stay folded.                         |
| Local publishing and saved logins | Clean work skips publishing; saved logins respect approved sites.        |

New profiles [record Claude Terminal sessions](settings.md#record-terminal-sessions) by default; existing choices stay. Codex is unchanged.
