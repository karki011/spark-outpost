Changes since the last release, newest first. For earlier ones, open **Release notes** in **Settings → Updates**.

## October 2026

| What changed                                                                                                                                                      | What to do                                                        |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| Agents can't read, copy or change your browser profiles or history on disk, in any mode.                                                                          | See [Protected paths](protected-paths.md#what-is-always-refused). |
| **Browser** in the left bar: **Personal** tabs no agent can reach, **Work**, favorites, a ⌘T bar with history and web search; chat or **Ask Spark** about a page. | See [Browse on your own](browse-on-your-own.md).                  |
| Chats idle 2 days, old ones too, move to **History** (**Archive inactive chats**). Empty projects leave **Projects**.                                             | See [Chat list](statuses-and-limits.md#chat-list).                |
| Mac app: the menu bar icon is off; **Show in menu bar** brings it back.                                                                                           | See [Island](desktop-companion.md#turn-it-on-and-size-it).        |
| Outposts: each chat does only its part of a message to several; questions offer **Answer**; title menu stays on top.                                              | See [Send a request](outposts.md#send-a-request).                 |
| Quieter chat: tool calls are rows named by tool, cards wait at the turn's end, details show on hover; **Esc** stops.                                              | See [Follow a turn](follow-a-turn.md#see-whats-happening).        |
| The message box styles Markdown as you type; **Aa** and a selection toolbar format it. **⌘B** now bolds.                                                          | See [Write a message](start-a-chat.md#write-a-message).           |
| Keyboard-reachable meeting cards; **⌃⌥⌘M**.                                                                                                                       | See [Calendar](calendar.md#use-it).                               |
| Appearance follows the system; pick a **Tint**.                                                                                                                   | Had a theme? It stays. [Settings](settings.md#general).           |
| Mac app: **Settings…** window (⌘,), **Hide Sidebar** (⌃⌘S), right-click editing; one-answer questions show radios.                                                | See [Keys](keyboard-shortcuts.md#chats).                          |
| Outposts: request cards, **Overview** (threads, files, PRs), a thread pane, **Instructions…**; no Browser pane at left.                                           | See [Send a request](outposts.md#send-a-request).                 |
| **To-do** replaces **Tasks**: the turn and the Work panel show the agent's to-do.                                                                                 | See [Follow a turn](follow-a-turn.md#see-whats-happening).        |
| A sent spoken question acts like a typed one (**When Ask Spark acts**).                                                                                           | See [Talk to Spark](voice.md#turn-it-on).                         |
