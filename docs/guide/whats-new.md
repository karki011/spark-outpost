| What changed                                                                                                              | What to do                                                |

| Prompt cache countdown, re-write notes and **Cache hit**.                                                                 | See [Prompt cache](statuses-and-limits.md#prompt-cache).  |
| Claude plan ring.                                                                                                         | See [Limits](statuses-and-limits.md#limits).              |
| **Revert file** undoes one file.                                                                                          | See [Review changes](review-changes.md#keep-or-revert).   |
| Compaction keeps exact PR numbers and commits.                                                                            | See [Manage a long chat](compaction.md#read-the-summary). |
| Calendar: **Today** from macOS or Google, on **Month** and the clock; nudges, **Join** at 10 min, **Choose** for clashes. | See [Use it](calendar.md#use-it).                         |
| Pull request **Refresh** no longer reverts.                                                                               | None.                                                     |
| Settings: six groups and **Search settings**.                                                                             | See [Settings](settings.md).                              |
| Push to talk: dictate, start chats or ask who needs you; speech stays local.                                              | See [Talk to Spark](voice.md).                            |
| Ask Spark is faster and remembers key facts.                                                                              | See [Settings](settings.md#spark-assistant).              |
| Allowed browser and Mac cards now tell the agent.                                                                         | See [Mac control](mac-control.md).                        |
| Without a project, Spark actions follow your mode.                                                                        | See [Spark tools](spark-tools.md#when-actions-ask-first). |
| Agents can read and press in another Mac app. Sends and deletes always ask.                                               | See [Mac control](mac-control.md).                        |
