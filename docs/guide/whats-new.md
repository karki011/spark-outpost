What changed recently in Spark, newest first.

## October 2026

| What changed                                                                       | What to do                                                |
| ---------------------------------------------------------------------------------- | --------------------------------------------------------- |
| Voice finds new projects.                                                          | None.                                                     |
| Calendar: see your day on **Today**, join meetings and keep focus time quiet.      | See [See your day](calendar.md).                          |
| Pull request **Refresh** no longer reverts.                                        | None.                                                     |
| Settings has six groups and a **Search settings** box.                             | See [Settings](settings.md).                              |
| Push to talk: dictate, start chats or ask who needs you. Speech stays on your Mac. | See [Talk to Spark](voice.md).                            |
| Ask Spark is faster and remembers key facts.                                       | See [Settings](settings.md#spark-assistant).              |
| Allowing a browser or Mac control card now tells the agent.                        | See [Mac control](mac-control.md).                        |
| Without a project, Spark actions follow your mode.                                 | See [Spark tools](spark-tools.md#when-actions-ask-first). |
| Agents can read and press in another Mac app. Sends and deletes always ask.        | See [Mac control](mac-control.md).                        |
