Changes since the last release, newest first. For earlier ones, open **Release notes** in **Settings → Updates**.

## October 2026

| What changed                                                                                                                                                                                                                                                                                        | What to do                                                                                                                                           |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| A chat folds steps between replies into one line, like **Ran 4 commands, thought 2 times**, shows the running step at the top while it works, titles commands by what they do or by their program (**Ran python3…**), folds background commands into one row, and shows passed in green everywhere. | Open the line or a command for its command, output and **You allowed it once** or **You denied it**; an answered command's card folds into its step. |
| Mac app: the Settings window opens larger.                                                                                                                                                                                                                                                          | Nothing; it still fits smaller screens.                                                                                                              |
| The prompt cache moved from the message box's chip to a badge on the context ring.                                                                                                                                                                                                                  | Hover or select the ring to read **Prompt cache** in words.                                                                                          |
| A chat no longer shows an "Allowed …" step for each command its mode ran without asking, in new and earlier chats.                                                                                                                                                                                  | Nothing; each one is still in the audit.                                                                                                             |
