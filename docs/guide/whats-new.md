## October 2026

| What changed                                                                                   | What to do                                                                                                                                                                                                                  |
| ---------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Implementation defaults to agent-led delegation in chats and new or resumed Terminal sessions. | Let the lead choose workers and slices; [Outposts remain optional](how-spark-works.md#how-work-is-split). Codex respects your agent settings.                                                                               |
| Agent TV opens messaging drafts with Outpost handles.                                          | **Message lead** or a member opens its composer; **Ask lead to redirect** prepares a request about a sub-agent. Drafts survive chat switches; recovery preserves typing. Redirects stay brief; nothing sends automatically. |
| Calmer Inter chat text, quieter composer, borderless worker row.                               | Use **View agents** for Work details, **Chat details** for branch/setup, and **+ → Formatting**. Chat and Agent TV share worker faces, roles and status.                                                                    |
| Publishing skips clean local work; saved logins explain site approval.                         | Local receipts report HEAD changes. Approve eligible HTTPS login sites in **Saved sign-ins**, then retry.                                                                                                                   |
