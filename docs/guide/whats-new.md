Changes since the last release, newest first. For earlier ones, open **Release notes** in **Settings → Updates**.

## October 2026

| What changed                                                                                                                                                                            | What to do                                                                         |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| Spark's rules live in `settings.json`, empty by default: your agent's mode decides, so **Bypass permissions** can force push or edit secret files. Agents ask to change them on a card. | Choose **Use recommended rules** in [Spark rules](protected-paths.md#spark-rules). |
| A refused step says what and why, such as "Refused gh pr create — …"; `gh -R owner/repo pr checks 5` is a read.                                                                         | Nothing.                                                                           |
| **Needs sign-in** clears once a test passes or you sign in again.                                                                                                                       | Nothing.                                                                           |
| **Good result** and **Bad result** show once per chat, under the turn that opened its pull request.                                                                                     | Rate it if you like.                                                               |
