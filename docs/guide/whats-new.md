## October 2026

| What changed                                                                                   | What to do                                                                                                                                                                                   |
| ---------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Implementation defaults to agent-led delegation in chats and new or resumed Terminal sessions. | Let the lead choose workers and slices; [Outposts remain optional](how-spark-works.md#how-work-is-split). Running Terminals keep existing instructions.                                      |
| Agent TV opens messaging drafts.                                                               | **Message lead** or a member opens its composer; **Ask lead to redirect** prepares a request about a sub-agent. Nothing sends automatically. Draft text survives chat switches, not reloads. |
| Calmer Inter chat text, quieter composer, borderless worker row.                               | Use **View agents** for Work details, **Chat details** for branch/setup, and **+ → Formatting**. Chat and Agent TV share worker faces and roles.                                             |
| Publishing honors explicit restrictions; saved logins explain site approval.                   | Say “do not commit” to keep work local. Approve a new login domain in **Saved sign-ins**, then retry.                                                                                        |
