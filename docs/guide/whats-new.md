Changes since the last release, newest first. For earlier ones, open **Release notes** in **Settings → Updates**.

## October 2026

| What changed                                                                                                                                                                                        | What to do                              |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------- |
| Browser pane: resize from 320 px to nearly the whole window, with **Page width** presets.                                                                                                           | Drag its edge.                          |
| Settings opens larger; the prompt cache is a badge on the context ring.                                                                                                                             | Hover the ring.                         |
| Steps fold into one line, titled by what they do; no automatic "Allowed" steps.                                                                                                                     | Open the line.                          |
| Messages sent mid-turn show **Sent**, then **Claude took this in**.                                                                                                                                 | After a stop: **Send as next message**. |
| Outposts: one-sheet drafts, existing chats can take sub-tasks, and the lead's chip says **· Lead**.                                                                                                 | Select **Review and start**.            |
| PR items close when resolved, passing or re-reviewed.                                                                                                                                               | Nothing.                                |
| **Bypass permissions**: `/tmp` scripts and secret reads follow your mode.                                                                                                                           | Nothing.                                |
| Fixed: chat picker overlap, long outpost handles, wide branch and folder menus, small touch menu rows, split words in replies, a script writing a secret file through a file descriptor not asking. | Nothing.                                |
