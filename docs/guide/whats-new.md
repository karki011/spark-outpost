What changed recently in Spark, newest first.

## October 2026

| What changed                                                                                                                                                                                                   | What to do                                 |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------ |
| **Phone** is now **Remote control**. Paired devices stay paired.                                                                                                                                               | See [remote control](use-your-phone.md).   |
| Agents can keep a command running after the turn: **Agent terminal**, with **Stop**.                                                                                                                           | See [Spark tools](spark-tools.md).         |
| **Open in terminal** on a reply's command mirrors it in a read-only tab.                                                                                                                                       | See [Open a terminal](terminals.md).       |
| Every agent of a chat is refused pushes of other branches and remote changes. Unreviewed ones are flagged.                                                                                                     | See [protected paths](protected-paths.md). |
| After `/plan` in an **Auto** or **Bypass permissions** chat, reads run without a card.                                                                                                                         | See [plans](plan-card.md).                 |
| A stacked sub-task starts with its parent's kept changes. A story whose chats are all refused creates nothing.                                                                                                 | See [stacks](stacked-pull-requests.md).    |
| A crew turn finished before you opened its chat shows no piece list or **Message**.                                                                                                                            | Use **Agent TV** or **Crew**.              |
| Outpost agents ask each other. A chat proposes a **story** of sub-tasks; you start it. Sub-tasks keep draft titles, can wait for another and stack pull requests; an early stacked push is refused or flagged. | See [stories](outpost-stories.md).         |
