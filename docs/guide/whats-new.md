What changed recently in Spark, newest first.

## October 2026

| What changed                                                                                                                                                                            | What to do                                                  |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| On a paired device, a Terminal session's **Deny** takes a reason, **Send now** stops the turn, and steps fold into one row.                                                             | See [remote control](use-your-phone.md).                    |
| In a Terminal session **Shift+Tab** stays with the agent and **⌥Tab** leaves the terminal. The bar says **Hold Option to select** when the agent uses the mouse.                        | See [terminals](terminals.md).                              |
| Selecting text in a Terminal session copies it and offers **Add to terminal** (**⌘⇧A**), **Ask about this**, **Comment** and **New chat with this**; you press Enter.                   | See [terminals](terminals.md).                              |
| **Pause** in the left bar holds the work Spark starts by itself; running turns and messages you send go on. A paired device can pause and resume too.                                   | See [pause automatic work](pause-spark.md).                 |
| A Terminal session starts from the message box. **Focus terminal** (**⌘⇧F**) fills the pane. **Stop session** is under **⋯**; **Hide view** is gone. Rows say **Terminal**, not **>_**. | See [terminals](terminals.md).                              |
| Search in **Sessions** and the chat list matches words from their start, shows the matching line and opens the chat at that message.                                                    | See [start a chat](start-a-chat.md#jump-between-sessions).  |
| Changing a repo's `.agents/` or `.codex/` folder, where agents keep skills and Codex settings, now asks like other agent instruction files.                                             | See [protected paths](protected-paths.md#what-always-asks). |
| A paired device can follow a Terminal session, send it a message, stop it and approve its requests. Two switches in **Remote control** turn this on; both start off.                    | See [remote control](use-your-phone.md).                    |
| Spark's fonts ship inside the app, so nothing is fetched from Google at start, and the terminal's bold is real.                                                                         | Nothing to do.                                              |
| Claude Code in a Terminal session follows Spark's theme, also after a theme switch, and a terminal's last line is no longer cut off.                                                    | Nothing to do.                                              |
| A starting Terminal session names its step and opens once its worktree exists; a line says while dependencies still copy.                                                               | See [terminals](terminals.md#start-a-terminal-session).     |
| **Sessions** (**⌘⇧K**) lists chats and Terminal sessions, waiting ones first. Spark Island and the companion show a Terminal session's steps and when a turn ends.                      | See [start a chat](start-a-chat.md#jump-between-sessions).  |
| A Terminal session keeps running when Spark restarts, updates or crashes, and says so in one line. **Quit** still stops it.                                                             | See [terminals](terminals.md#close-and-recover).            |
