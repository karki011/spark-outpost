Ask about a repo the chat lacks, like "the identity repo". About 1 minute.

## Set your repos folders

1. In **Settings → Projects**, under **Repos folders**, select **Add repos folder…**.
2. Choose where you clone repos.

## Link a repo by name

The agent searches projects and **Repos folders**, then asks on a **Link** card in every mode. The chat uses the repo from your next message.

## Clone or read a repo from GitHub

With GitHub connected, the agent can search your account and organizations. A **Clone and link** card, in every mode, clones the repo into your first repos folder and links it. A repo already here gets **Link** instead.

To answer a question now, the agent can copy a repo just to read it: shallow, with no hooks or submodules, and deleted with the chat. Searching and copying ask first unless the agent's mode acts at once.
