Make a named teammate, chat with it and hand it jobs. About 2 minutes.

## Make one

1. On **Home**, find **Your Sparks**.
2. Select **New Spark**, or **Add** on a suggestion such as **Pip · Code reviewer**.
3. Type a **Name** and **Role**; **Change look** picks the blob.
4. Under **Defaults for its chats**, pick the **Provider**, **Model**, **Mode**, **Spark autonomy** and **Default project**.
5. Write **Standing instructions**, or select **Use a file…**.
6. Select **Create Spark**.

A file replaces the typed text: Markdown or text, up to 256 KB, first 2,000 characters. No secret files.

## Talk to it

| To                         | Do                                                                |
| -------------------------- | ----------------------------------------------------------------- |
| Open its home chat         | Select its card on **Home**.                                      |
| Start another chat with it | Before the first message, select **Talk to…** in the message box. |
| See only its chats         | Search chats for `with:` plus its name (`with:ada`).              |

A Spark sets starting defaults and adds instructions; approvals and protected paths never change.

## Hand it one job

In any chat, type `@` and pick a Spark, or select the **Ask Pip (Code reviewer)?** chip.

- It works as a read-only subagent with its own context, replying in the chat.
- The chat's agent gets a short note, and runs only if your message goes on: `@Pip review this, then fix it`.
- Up to three Sparks run in turn. Mode and approvals never widen.

## Change or delete one

1. Point at its card on **Home** and select **Edit**, or open **Settings → Crew**.
2. Edit and select **Save**.
3. To delete it, select **Delete** in **Settings → Crew** and hold **Hold to delete**. **Undo** lasts 10 seconds. Its chats stay.
