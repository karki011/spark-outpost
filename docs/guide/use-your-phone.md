Use Spark from another device; work stays on the Mac. About 5 minutes. Needs Tailscale on both, HTTPS certificates on.

1. Open **Remote control**, above **Settings**, and turn it on.
2. Select **Pair a device**, then scan the code, or open the address and type it.
3. Check the codes match, then **Confirm**.

**Passkey.** On the device, select **Save a passkey for this device**, then **Sign in with a passkey** in another browser. It never pairs a new device. **Devices** has **Allow passkey sign-in** and **Remove passkeys**.

**Devices** renames or revokes a device, passkeys included; **Remove old entry** clears a duplicate. **What paired devices can do** holds the switches. On a phone, **More** holds Remote control and Settings; Mac-only tools are hidden.

See what [outposts](outposts.md) allow here.

**Link a new folder or clone a repo** also allows **New folder**.

Devices answer browser cards. **Open artifacts** (off) shows artifacts.

**Terminal sessions.** **Follow, type in and stop Terminal sessions** shows a session's messages and steps, a message box and **Stop**. **Approve in Terminal sessions** adds **Deny** and **Allow**. Both start off.

**Send now** stops the turn first. Claude's terminal shows **Spark · phone connected**. Messages shown aren't stored.

**Awake.** With Remote control on, work or a connected device keeps the Mac awake, except a closed lid on battery.

**Notifications.** Turn on **Notify when a chat needs you** on the Mac, then **Notify this device**. Pushes name the chat, never a command; [meeting alerts](calendar.md) say "Meeting in 10 min". Seen chats and the device you're using get none.

iPhone needs iOS 16.4 or later and Spark on the Home Screen: save a passkey, then sign in with it there.
