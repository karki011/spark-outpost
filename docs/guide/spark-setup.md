Choose what a Spark runs on and where it is used. About 2 minutes.

## Choose what it runs on

1. Select **Sparks** in the left bar, then the Spark's card. It opens on **Setup**.
2. Under **Runs on**, pick the **Provider**, **Model**, **Effort**, **Mode** and **Spark autonomy**. Each choice saves at once.
3. Read **What this means**. It says whether the Spark only reads, changes files with or without asking, and opens a pull request.

Chats with the Spark use a new provider, model, effort or mode from their next turn, and show one line saying so.

A chat with a turn running, and an archived chat, keep what they had. **Spark autonomy** and the project apply to new chats only.

## Use it for new chats

1. On **Setup**, turn on **Use for new chats**. The line under it names the Spark new chats use now.
2. Start a new chat. The message box shows **Talking to** and the Spark's name.
3. To change one chat, select that chip before the first message and pick **No Spark** or another Spark.

One Spark at a time. Sub-chats, workflow chats, meeting chats, Ask Spark and Terminal sessions never use it.

## See where it is used

| Look at      | To see                                                                       |
| ------------ | ---------------------------------------------------------------------------- |
| **Used in**  | Workflows whose steps name the Spark, and Sparks whose instructions name it. |
| **Activity** | Its chats, `@` jobs and workflow steps, with the last use, tokens and cost.  |
| **Open**     | The workflow or Spark on a **Used in** row.                                  |

Deleting a Spark lists what still uses it above **Hold to delete**.
