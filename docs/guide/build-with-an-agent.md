Describe a Spark or a workflow and let an agent draft it. About 3 minutes.

## Open the builder chat

1. Select **Sparks** in the left bar, then **Let Spark build one for you**. Or open the status companion in the corner and select **Build a Spark or workflow**.
2. The chat opens beside the page with your default provider; drag its left edge to resize it. Another provider in the composer starts a new agent session.
3. Say what you want, such as "a Spark that reviews release notes".

A builder chat that isn't **Done** opens again when you come back.

## Change one Spark

1. Open a Spark and select **Ask an agent**. Its own chat opens on the right.
2. Ask, such as "add a changelog skill". The agent adds, changes, moves or deletes files and folders, one card per change.

## Answer the drafts

Each proposal shows in the chat as one line, such as **Gavel is ready for review**. **Review** opens it in a window, formatted; **Source** shows the exact text, and text with HTML or comments opens there.

Nothing is written until you select **Allow**. Esc closes the window without answering.

A new Spark or workflow waiting for you also shows at the top of the page as **Draft · waiting for you**; its **Review** opens the same window.

## Finish

1. Answer the drafts first: a waiting card is dropped when the chat is removed. Then select **Done**.
2. Spark removes the chat 24 hours later. A new message before then reopens it. **New chat** starts a fresh one.

Without **Done**, the chat goes after your **Archive inactive chats** period unless a draft waits. Sparks and their files stay.

The builder chat never shows in your chats, History, Updates or the island, and a paired device can't open it.
