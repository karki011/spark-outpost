About 1 minute. Mac app only.

## Open a page

1. Select **Browser** in the left bar.
2. Pick **Personal** or **Work**.
3. Type an address; press **Enter**.

## Pick a profile

| Profile      | Who reaches it                                           |
| ------------ | -------------------------------------------------------- |
| **Personal** | Only you; no agent or phone opens or lists its tabs      |
| **Work**     | You; chats' agents share its sign-ins but not these tabs |

## Find a page

**⌘T** or **⌘L** opens the command bar: tabs, favorites and this profile's local history.

The last row searches the web; only choosing it sends what you typed.

## Keep and share tabs

- **+** under **Favorites** saves the page; **Pin** keeps a tab above **Today**.
- **Hand to chat** gives a chat the page: a **Work** tab moves there; from **Personal** only the address goes.
- In a chat's pane, **Open in Browser view (Work)** moves the tab here.

## Split view and Peek

**Split view** in the page bar, or **Shift-Option-click** a link, shows two tabs of one profile. Drag the divider; closing a side leaves.

**Shift-click** a link to **Peek**: **Esc** closes it, **Open as tab** keeps it.

## Start a chat from a page

**New chat** (**⌘⇧O**), a right-click or **Select** opens a chat at **Automatic** beside the tab. The page goes as an untrusted attachment when sent; **Personal** picks go as text only.

## Ask Spark about your tabs

**Ask Spark** (**⌥⌘A**) opens beside the tab; type **@** to add tabs. Spark reads them once, as text, when sent; its actions are cards.

## Save a file

A file saves only after your click. One an agent or page started is cancelled.
