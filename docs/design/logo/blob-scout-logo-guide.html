Using it

  • Leave space around it equal to the height of one eye.
  • Smallest size is 16 px. Below 24 px, use the favicon file, which has a thicker antenna.
  • One color: use the black or white file. The eyes are cut out, so it works on any background.
  • Wordmark is "spark outpost" in lowercase Bricolage Grotesque, weight 800, tight letter spacing.
  • Don't recolor the eyes, stretch the body, or remove the spark.
