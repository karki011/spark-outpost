# Contributing

Spark Outpost does not accept pull requests.

- **Found a bug or have an idea?** [Open an issue](https://github.com/karki011/spark-outpost/issues).
- **Want to change it?** Fork it for any non-competing use; the [Functional Source License](LICENSE) allows that. [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md) covers running it from source.
- **Found a security problem?** Follow [SECURITY.md](SECURITY.md), never a public issue.
